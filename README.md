# POS (Point of Sale)

**Description**
A POS System, made with Claude & Gemini AI. 

# Requirements
- Windows 10/11 or Linux
  
To run this build you need:
- .NET 8 SDK

# Dependencies
- SQLite
- Avalonia 11.2
- Avalonia.Desktop 11.2
- Avalonia.Themes.Fluent 11.2
- Microsoft.Data.Sqlite 8
